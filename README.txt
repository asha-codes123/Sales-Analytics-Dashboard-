# 📊 Sales Analytics & Business Intelligence

A beginner-friendly **Sales Analytics & Business Intelligence** project designed to transform raw sales data into meaningful business insights through data analysis and visualization.

The project focuses on understanding sales performance, identifying trends, comparing products and categories, analyzing regional performance, and finding areas that need improvement.

## 📌 Project Overview

This project analyzes sales data to answer important business questions such as:

* What are the overall sales and profit?
* How do sales change over time?
* Which products and categories perform best?
* Which regions generate higher sales?
* Which products or categories have low performance?
* What are the customer purchasing patterns?
* Which months or periods show higher or lower sales?
* Where can the business improve its performance?

## ✨ Key Features

## 📊 Analysis Performed

### 1. Sales Performance

Analyzes overall sales performance and helps identify changes in revenue over different time periods.

### 2. Product Analysis

Identifies high-performing and low-performing products based on sales and profitability.

### 3. Category Analysis

Compares different product categories to understand which categories contribute more to overall sales.

### 4. Regional Analysis

Analyzes sales performance across different regions to identify stronger and weaker markets.

### 5. Customer Analysis

Studies customer purchasing patterns and helps understand customer contribution to sales.

### 6. Profitability Analysis

Compares sales and profit to identify profitable and loss-making areas of the business.

### 7. Seasonal Trends

Examines sales patterns over time to identify high-sales and low-sales periods.

## 🎯 Business Insights

The dashboard helps users:

* Understand overall business performance
* Identify profitable products and categories
* Find underperforming products
* Compare regional performance
* Track sales trends over time
* Understand customer purchasing behaviour
* Identify possible seasonal patterns
* Support better business decision-making

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/asha-codes123/Sales-Analytics-Dashboard.git
```

2. Open the project folder:

```bash
cd Sales-Analytics-Dashboard
```

3. Open the project in **VS Code**.

4. Run the project using a local development server such as **Live Server**, or open the HTML file in your browser.
